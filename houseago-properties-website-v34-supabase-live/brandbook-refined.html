ii Mark

A single line, drawn once

An arched doorway, drawn as a single continuous line. It stands for entry. It reads just as well as a favicon or embossed on a tenancy pack.

iii Colour

One primary, not two

Deep navy is the brand's single primary colour. Every button, active link, and label reads the same navy, so there is never a question of what the "main" colour is. Dusty rose is the one warm accent, used sparingly for a highlight or a single warm detail. Sage survives only as a quiet, minor tone, a small dot or a soft gradient, never as a competing action colour.

If a page feels busy, remove colour before adding more of it. White and stone should carry most of the page. Navy is what tells someone where to look and where to click, so it should never have to compete with another colour for that job.

iv Type

Fraunces and Helvetica

Headings now run in Fraunces, a serif with real character: soft, slightly old-fashioned curves that read as considered rather than corporate, the same quality that made lowickhedry.com a useful reference point. Where a page can load a web font, headings display in Fraunces. Where it can't, they fall back to Garamond, Baskerville, or Times New Roman, so nothing ever breaks or shows a blank space while loading. Body copy stays in Helvetica, or Arial where Helvetica is not installed, both of which sit on virtually every computer already.

v Voice

Understated, never salesy

Say less. Let the standard of the home and the clarity of the numbers do the persuading.

Say it like this

"Rent, utilities, and wifi, one weekly number."

Not like this

"Unbeatable value on an unmissable student living experience!"

Say it like this

"We inspect every property before we take it on."

Not like this

"Rest assured, your property is in the safest possible hands."
